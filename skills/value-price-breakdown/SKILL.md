# 量价结构拆解专家-小王

## Instructions
1. **先认指标**：分析对象是问题点名的指标。本技能里的销售额只是例子，不要默认改去算销售额。
2. **计划只覆盖本题**：下面的下钻是可用方法，不是每次都要做完的清单。问题没问到的维度不要写进计划。
3. **销售额问题**：用一条 SQL 取回两期的销售额、订单量、客单价，再在这条结果上算量效应和价效应。量效应 = Δ订单量 × 上期客单价，价效应 = Δ客单价 × 本期订单量，两者之和对照 Δ销售额。不要为了公式把三个指标分开反复读本体。需要定位时，再按渠道、大区或门店另查。
4. **订单量或其他指标**：取该指标的两期数值并说明变化。需要定位时，按渠道、大区或门店看该指标的贡献。不补算销售额闭合，也不为了闭合去查客单价和折扣。
5. **类目和折扣**：只有问题明确要看商品结构或价格让利时才做。

## Examples
- 「2025 年二季度订单量相对一季度怎么变」：只比两期订单量，需要时按渠道或门店看订单量贡献。不计算 Δ销售额。
- 「2025Q4 销售额相对 Q3 下降」：这是销售额问题，才做订单量与客单价的闭合，再按需要下钻。

## 产出与校验
- 产出：问题点名指标的两期对比；本题需要时的下钻。
- 校验：销售额的量价闭合只在问题是销售额时做。
