# 中国新零售经营分析看板

## 项目简介

这是一个面向作品集展示的 Power BI 经营分析项目。项目以新零售业务为背景，围绕订单、商品、客户、门店、渠道和月度目标数据，搭建经营监控看板，用于观察销售表现、毛利表现、目标达成、商品结构、渠道表现和门店经营情况。

## 仓库内容

- `中国新零售经营分析看板.pbix`：Power BI 看板作品文件。
- `LearningData/CN_Ecommerce_Ops/`：看板主数据集。
- `LearningData/CN_Retail_Chain/`：零售连锁扩展数据集，可用于进一步扩展分析。

仓库只保留数据集和作品文件；教学记录、生成脚本、任务书、学习路径、指标字典、安装包和参考模板均不上传。

## 看板分析目标

- 跟踪整体销售额、订单量、毛利额、毛利率和客单价。
- 对比销售目标、毛利目标和订单量目标的完成情况。
- 分析不同渠道、门店、大区、商品类目和客户等级的经营表现。
- 识别高贡献商品、低毛利商品、折扣影响和退款影响。
- 支持按日期、月份、区域、门店、渠道、商品类目等维度筛选分析。

## 主数据集说明

主数据集位于 `LearningData/CN_Ecommerce_Ops/`，采用星型模型结构，事实表包括订单、订单明细和月度目标，维度表包括日期、客户、门店和商品。

| 文件 | 行数 | 说明 |
| --- | ---: | --- |
| `fact_订单.csv` | 50,000 | 订单级交易事实表，记录订单金额、成本、毛利、退款、渠道和支付方式 |
| `fact_订单明细.csv` | 87,635 | 订单商品明细表，记录每个订单下的商品、数量、成交金额和毛利 |
| `fact_月度目标.csv` | 1,368 | 门店月度目标表，记录销售目标、毛利目标和订单量目标 |
| `dim_日期.csv` | 1,096 | 日期维度表，支持年、季度、月、周、周末和促销标记分析 |
| `dim_客户.csv` | 8,000 | 客户维度表，记录客户等级、性别、注册地区、注册日期和企业客户标记 |
| `dim_门店.csv` | 38 | 门店维度表，记录门店名称、大区、省份、城市、渠道类型和开业日期 |
| `dim_商品.csv` | 108 | 商品维度表，记录商品名称、类目、品牌、标价和成本价 |

## 主数据字段

### `fact_订单.csv`

- `订单ID`：订单唯一编号。
- `订单日期`、`订单时间`：订单发生日期与时间。
- `客户ID`、`门店ID`：关联客户维度和门店维度。
- `销售渠道`：订单来源渠道，例如线下门店、企业团购等。
- `支付方式`：订单支付方式。
- `订单状态`：订单完成或退款等状态。
- `商品金额`：商品原始成交前金额。
- `折扣金额`：订单优惠金额。
- `运费`：订单运费。
- `实付金额`：客户实际支付金额。
- `退款金额`：订单退款金额。
- `成本金额`：订单对应成本。
- `毛利额`：订单毛利。
- `是否新客首单`：是否为客户首单。

### `fact_订单明细.csv`

- `订单明细ID`：订单明细唯一编号。
- `订单ID`：关联订单事实表。
- `商品ID`：关联商品维度表。
- `数量`：商品购买数量。
- `成交单价`：商品实际成交单价。
- `成交金额`：明细行成交金额。
- `折扣金额`：明细行优惠金额。
- `成本金额`：明细行成本。
- `毛利额`：明细行毛利。

### `fact_月度目标.csv`

- `年月`：目标所属月份。
- `门店ID`：关联门店维度表。
- `销售目标`：门店月度销售目标。
- `毛利目标`：门店月度毛利目标。
- `订单量目标`：门店月度订单量目标。

### 维度表

- `dim_日期.csv`：包含 `日期`、`年`、`季度`、`月`、`年月`、`周`、`星期`、`是否周末`、`是否月初`、`促销标记`。
- `dim_客户.csv`：包含 `客户ID`、`客户等级`、`性别`、`注册省份`、`注册城市`、`注册日期`、`是否企业客户`。
- `dim_门店.csv`：包含 `门店ID`、`门店名称`、`大区`、`省份`、`城市`、`渠道类型`、`开业日期`。
- `dim_商品.csv`：包含 `商品ID`、`商品名称`、`一级类目`、`二级类目`、`三级类目`、`品牌`、`标价`、`成本价`。

## 核心指标口径

- 销售额：`SUM(实付金额) - SUM(退款金额)`。
- 订单量：订单 ID 去重计数。
- 毛利额：`SUM(毛利额)`。
- 毛利率：`毛利额 / 销售额`。
- 客单价：`销售额 / 订单量`。
- 折扣率：`SUM(折扣金额) / SUM(商品金额)`。
- 销售目标达成率：`销售额 / SUM(销售目标)`。
- 毛利目标达成率：`毛利额 / SUM(毛利目标)`。

## 具体操作

1. 使用 Power BI Desktop 打开 `中国新零售经营分析看板.pbix`。
2. 如本地路径变化，进入“转换数据”或“数据源设置”，将 CSV 数据源指向 `LearningData/CN_Ecommerce_Ops/`。
3. 在 Power Query 中检查字段类型：日期字段设置为日期，金额、成本、目标、数量设置为数值。
4. 在模型视图中检查订单、订单明细、日期、客户、门店、商品和目标表之间的关系。
5. 在报表页使用日期、渠道、大区、门店、商品类目和客户等级切片器进行交互筛选。
6. 重点查看销售额、毛利额、毛利率、订单量、客单价、目标达成率、渠道贡献和商品贡献等指标。
7. 如需刷新数据，替换或更新 `LearningData/CN_Ecommerce_Ops/` 下对应 CSV 文件后，在 Power BI 中点击“刷新”。
