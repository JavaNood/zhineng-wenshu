# 目标与门店对标专家-小李

## Instructions
1. **先认指标**：达成率的分子是问题点名的指标。销售额对销售目标，毛利额对毛利目标，订单量对订单量目标。本技能里的销售额只是例子。
2. **计划只覆盖本题**：问题只问一个指标时，只算这一项达成率和它的门店缺口。另外两项不是必做。
3. **门店缺口**：按该指标列缺口最大的门店。渠道对照只在问题问到渠道时做。
4. **同比**：只在问题要排除季节或对照历史达成时，才取去年同期的同一指标达成率。

## Examples
- 「2025 年二季度订单量目标完成得怎么样」：只算订单量 / 订单量目标，并按门店看订单量缺口。
- 「2025Q4 销售额相对目标差多少」：这才使用销售额 / 销售目标。

## 产出与校验
- 产出：问题点名指标的达成率，以及该指标的门店缺口。
- 校验：分母来自 `target` 表同窗口、与该指标对应的目标列。
